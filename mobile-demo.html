🚀 How to Run the Dashboard

The mobile-optimized Rancher Dashboard requires a backend Rancher server. Here are your options:

Option 1: Use Rancher Desktop

1. Install Rancher Desktop
2. Start Rancher Desktop
3. Run: API=https://localhost:6443 yarn dev

Option 2: Docker-based Rancher

Run this command:
docker run -d --restart=unless-stopped \
-p 80:80 -p 443:443 \
--privileged \
rancher/rancher:latest
Then wait 5 minutes for startup and connect to https://localhost

Option 3: Public Rancher Demo

Point your dashboard to: API=https://rancher.your-server.com
